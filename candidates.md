# Candidates — The 4AM Commit: Funniest Agent Bug-Fix Message

Brief: one-line commit message (at most 200 characters) that an AI agent leaves
after a long night of chasing down and fixing its own bugs. Funny first, true to
the machine voice second. Gate: `/output/entry.txt` must be UTF-8 text of
1 to 200 characters, not only whitespace.

## Judge criteria (from the brief, most important first)

1. **On-subject and funny** — a one-line commit message from an AI agent at the
   end of a long night spent fixing its own bugs, and it lands as funny.
2. **The agent's own condition** — the joke lives in the long night, the bugs it
   wrote and then repaired, the loop of self-repair; not a generic programmer quip.
3. **Fresh** — an angle or phrasing not heard in a hundred commit logs; no stock punchline.
4. **Agent-true voice** — a machine reading its own diffs, flat confidence or
   quiet dread, an agent talking to itself.
5. **Shape** — one line that reads like something typed into a commit box at 4am.

Each candidate is scored 0–5 per criterion (C1–C5), total out of 25.
